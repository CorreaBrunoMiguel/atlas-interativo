# Atlas Digital Interativo do Brasil (FullStack Humanizado – MVP v0.1)

## Visão do Projeto

Este projeto é um **Atlas Digital Interativo do Brasil**, focado em indicadores sociais e populacionais, com dados confiáveis do **IBGE**.  
Ele tem como objetivo demonstrar habilidades técnicas **FullStack** e **integração com análise de dados**, servindo como portfólio profissional.

## Estrutura de Pastas

### Backend

- `/src/controllers`: Lógica de controle de rotas e endpoints
- `/src/models`: Modelos e entidades do banco de dados
- `/src/routes`: Definição de rotas REST
- `/src/config`: Configurações de ambiente, banco e API

### Frontend

- `/src/components`: Componentes reutilizáveis do React
- `/src/pages`: Páginas principais da aplicação
- `/src/services`: Serviços de consumo de API
- `/src/styles`: Arquivos de estilo (Tailwind/Custom CSS)
